# Captive-Portal
Captive Portal com ESP32
Captive Portal com ESP32 — Este repositório contém artefatos de um estudo acadêmico sobre captive portals usando ESP32 (compatível com core 3.2.0). O objetivo é analisar fluxos de autenticação, experiência do usuário e riscos em ambientes IoT, tudo executado em ambiente de laboratório controlado.
Importante: Este projeto não contém código destinado a capturar, armazenar ou exfiltrar credenciais reais. Não realize transmissões ou testes em redes sem autorização.
